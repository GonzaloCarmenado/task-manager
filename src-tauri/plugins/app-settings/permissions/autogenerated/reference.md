## Default Permission

Permite consultar si se pueden programar alarmas exactas y abrir los ajustes del sistema
de notificaciones y de alarmas y recordatorios. No da acceso a datos ni a ficheros.

#### This default permission set includes the following:

- `allow-can-schedule-exact-alarms`
- `allow-open-notification-settings`
- `allow-open-exact-alarm-settings`
- `allow-launch-notification-id`
- `allow-schedule-alarms`
